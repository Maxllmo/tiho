# Tiho

Простой Windows-клиент для AmneziaWG. Начинает с пустыми настройками и не переносит данные ProxyHub.

## Установка

Запустите `output/Tiho-Setup.exe`. Установщик выбирает нативную сборку для Windows 10/11: x64, ARM64 или x86. Нужны права администратора для виртуального адаптера. .NET, ядро AmneziaWG, sing-box и списки маршрутизации уже входят в установщик; загрузок при установке нет.

В приложении откройте **Настройки → Импорт AmneziaWG .conf**, выберите клиентскую конфигурацию, затем подключитесь. Нужен файл с одним `[Interface]` и одним `[Peer]`, а не конфигурация сервера. Старые настройки и логи ProxyHub не читаются.

## Поведение

- TUN перехватывает TCP и UDP всего компьютера. Трафик к серверу и локальным сетям исключён из захвата.
- Российские домены и IP направляются напрямую. В комплекте 1 164 правила доменов и 25 244 IPv4/IPv6-префикса. Списки можно обновить в настройках; для отсутствующего сервиса можно добавить свой домен. Географические списки не гарантируют распознавание каждого российского сервиса, особенно общих CDN.
- Исключения программ применяются перед DNS, распознаванием протокола и географическими правилами. Выберите конкретные `.exe`; дочерние процессы с другими исполняемыми файлами добавляются отдельно. Исключённые соединения выходят с IP провайдера.
- Автозапуск через Планировщик заданий работает при входе текущего пользователя, с правами для TUN. Окно можно закрыть в трей; «Выход» в трее завершает туннель. После падения ядра приложение повторяет подключение с задержкой до 30 секунд. Это не системная служба до входа пользователя и не kill switch.
- Длительность считает время работы туннеля; скорость — фактический поток за интервал обновления; пинг — задержка HTTPS-запроса через сервер, а не ICMP. Счётчики включают отправленные и принятые данные через Tiho, включая обработанные ядром прямые соединения. Общие значения сохраняются между запусками; ГБ десятичные. Резкое завершение может потерять последние 10 секунд статистики.
- Логи находятся только в памяти текущего запуска, ограничены 1 500 строками. На диск автоматически не записываются. При закрытии очищаются.
- Ключи и пароли сохраняются через Windows DPAPI для текущей учётной записи. Ядра получают конфигурацию через stdin; plaintext-конфиги и ключи не передаются через аргументы командной строки и не сохраняются во временные файлы.
- HTTP/Squid и SOCKS5 можно добавить отдельно. Squid поддерживает TCP; UDP для него отклоняется, а не отправляется напрямую. Для игр используйте AmneziaWG. ICMP через промежуточный SOCKS-шлюз не поддерживается.

## Сборка

На Windows нужны .NET SDK 8, Go 1.25+ и NSIS 3.11+. Запустите:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

Скрипт проверяет SHA-256 скачанных официальных архивов, компилирует AWG-шлюз и приложение под три архитектуры и собирает `output/Tiho-Setup.exe`. Секретов и готовых конфигураций сервера в сборке нет. Разработка и проверки Windows-проекта на Linux: `dotnet build ProxyHub/ProxyHub.csproj -p:EnableWindowsTargeting=true`.

## Проверки

```text
dotnet run --project tests/Tiho.Checks.csproj
cd awg-core
go test -race ./...
```

Проверяются импорт конфигурации, прямые маршруты России, порядок исключений приложений, защита от циклов TUN, счётчики и восстановление статистики. Go-тесты создают два реальных узла AmneziaWG и передают TCP и UDP через зашифрованный туннель. Сгенерированные конфиги дополнительно проверяются `sing-box check`.

Windows TUN, Планировщик заданий, UI и установка требуют отдельной проверки на настоящей Windows. Сборка и сетевые тесты в Linux не заменяют эту проверку.
