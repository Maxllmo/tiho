# Где взять .conf для Tiho

Нужна **клиентская конфигурация** AmneziaWG — отдельный профиль устройства. Серверный `/opt/amnezia/awg/awg0.conf` импортировать не нужно: он содержит другие ключи и адреса.

Эта инструкция подходит для сервера, на котором AmneziaWG работает в контейнере `amnezia-awg2`. Помощник создаёт ключи устройства, выбирает свободный IP, сохраняет резервную копию конфигурации сервера и добавляет только нового клиента. Контейнер и Squid не перезапускаются. Ключи не печатаются в терминал.

## Получить файл на Windows

1. Скачайте весь репозиторий через **Code → Download ZIP** и распакуйте целиком.
2. В папке **release** запустите **Get-Config.cmd**.
3. Введите IP сервера из личного кабинета Amnezia Hosting. Только адрес, без `http://` и без порта.
4. Вводите пароль пользователя `root`, когда SSH/scp его запросят. Символы при вводе не отображаются — это нормально. Пароль потребуется несколько раз: при загрузке помощника, запуске и скачивании результата. В файл пароль не сохраняется.
5. Помощник откроет папку с готовым `.conf` в «Загрузках».
6. В Tiho откройте **Настройки → Импортировать .conf**, выберите полученный файл. На главном экране нажмите **Подключить**.

Имя профиля берётся из имени компьютера, например `Tiho-DESKTOP-123.conf`. Для каждого компьютера создаётся отдельный профиль. Готовые профили не перезаписываются. Если профиль уже был создан, его можно повторно скачать с сервера.

Помощник загружается на сервер через scp из скачанного репозитория. Публичный доступ к GitHub с сервера не нужен, поэтому способ подходит и для приватного репозитория.

## Если хотите выполнить вручную

Откройте PowerShell **в корне распакованного проекта**. Вместо `IP_СЕРВЕРА` подставьте адрес из кабинета:

```powershell
scp .\build\create-client.py root@IP_СЕРВЕРА:/root/tiho-create-client.py
ssh root@IP_СЕРВЕРА "python3 /root/tiho-create-client.py --endpoint IP_СЕРВЕРА --check"
ssh root@IP_СЕРВЕРА "python3 /root/tiho-create-client.py --endpoint IP_СЕРВЕРА --name Tiho-PC"
scp root@IP_СЕРВЕРА:/root/tiho-clients/Tiho-PC.conf "$env:USERPROFILE\Downloads\Tiho-PC.conf"
```

Команда с `--check` только проверяет сервер и не меняет настройки. Для другого устройства используйте другое имя, например `Tiho-Laptop`.

## Что происходит после импорта

Импорт сам по себе не включает VPN. После нажатия **Подключить** TCP/UDP-трафик ПК идёт через туннель, а российские ресурсы и выбранные программы-исключения — напрямую. Автоподключение при следующих запусках настраивается отдельно.

Клиентский `.conf` содержит приватный ключ. Не отправляйте его в чат и не добавляйте в Git. Папка `/root/tiho-clients/backups` на сервере содержит серверную резервную копию — её скачивать и импортировать не нужно.
