# Установка Tiho из GitHub

1. На главной странице репозитория нажмите **Code → Download ZIP**.
2. Распакуйте скачанный архив целиком.
3. Откройте папку **release** и запустите **Install-Tiho.cmd**.
4. Подтвердите запуск установщика с правами администратора.

Скрипт проверит контрольные суммы, соберёт части архива и извлечёт `ready/Tiho-Setup.exe`. Ничего дополнительно скачивать или собирать из исходников не нужно. Архиватор не требуется: используется PowerShell, который входит в Windows 10/11.

Если нужно только извлечь установщик, запустите `Restore-Tiho.ps1` через PowerShell без параметра `-RunInstaller`. Файлы `.001`, `.002` и следующие — части одного ZIP, они должны лежать рядом со скриптами. По отдельности их открывать не нужно.

Установщик включает x64, ARM64 и x86 и сам выбирает архитектуру ПК. Для подключения нужен клиентский `.conf` AmneziaWG. Старые настройки ProxyHub не импортируются, логи не сохраняются после выхода.

Если конфигурации ещё нет, запустите **Get-Config.cmd** из этой же папки, введите IP сервера и пароль root на запросы SSH. Он создаст отдельный профиль и сохранит его в «Загрузки». [Подробная инструкция](../docs/amnezia-config.md). Если скачивание оборвалось, повторно запустите **Get-Config.cmd**: существующий профиль будет проверен и скачан без создания нового клиента. После импорта нажмите «Подключить»; сам импорт VPN не включает.
